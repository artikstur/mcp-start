# Skill: Расписание ИФМиБ КФУ

Используй `get_group_schedule` для вопросов о расписании академической группы.

Правила:
1. Определи группу.
2. Передай дату, если пользователь её указал.
3. Не используй расписание, записанное в skill.
4. Если tool сообщает `not_found_in_public_documents`, не придумывай пары.
5. Укажи источник, если он вернулся.
6. Если публичный источник не содержит группу, сообщи, что официальный сайт
   ИФМиБ направляет студентов в ИАС «Электронный университет».
